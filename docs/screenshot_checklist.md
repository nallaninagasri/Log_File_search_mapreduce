# Screenshot checklist

Capture real screenshots from your laptop:
1. Flask home page.
2. Upload a .log file and show results.
3. ERROR/WARNING/INFO counts.
4. Terminal after running `py scripts/analyze_logs.py`.
5. `visualizations/logs_by_severity.png`.
6. `visualizations/logs_by_service.png`.
7. Hive query file in your editor (claim execution only if actually run in Hive).

Do not use fabricated screenshots as proof of execution.
